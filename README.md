# 🌆 CitySense AI

### Explore smarter. Travel safer. Experience your city.

CitySense AI is an AI-powered city exploration platform designed to help people discover local attractions, explore cultural landmarks, understand weather conditions, and access trustworthy safety information.

Built for **PromptWars**, this project aims to transform scattered city information into useful, accessible insights for everyday urban life.

## ✨ Features

* 🗺️ **Interactive City Maps** — Explore locations and nearby points of interest.
* 📍 **Multi-City Exploration** — Discover attractions, restaurants, parks, hospitals, and historical landmarks across cities.
* 🌦️ **Live Weather** — Access current weather conditions and forecasts.
* 🛡️ **Safety Information** — Find relevant official emergency resources and distinguish verified information from unverified reports.
* ⚖️ **City Comparison** — Compare cities using available, clearly explained data.
* 📝 **Citizen Reports** — Support community-submitted observations with appropriate verification labels.
* 🤖 **AI-Powered Recommendations** — Help users find places and plan city experiences.

## 🎯 Problem Statement

**City Life: Exploring, Experiencing & Navigating the Chaos We Call Home**

City life offers opportunities for exploration but also challenges such as traffic, unpredictable weather, unfamiliar locations, and safety concerns.

CitySense AI aims to make city exploration smarter by bringing useful geographic, weather, cultural, and safety information together in one platform.

## 🛠️ Technology Stack

* HTML, CSS and JavaScript, or the framework generated by the development environment
* Google Antigravity for AI-assisted development
* Leaflet and OpenStreetMap for interactive maps and geographic information
* Open-Meteo for weather data
* Public geographic data APIs for nearby places
* GitHub for version control and project collaboration

## 🚀 Getting Started

### Run locally

If the project contains a standalone `index.html` file:

1. Open the project folder in VS Code or Google Antigravity.

2. Start a local server from the project directory:

   ```bash
   py -m http.server 8000
   ```

3. Open your browser and visit:

   http://localhost:8000

If the project uses a framework, follow the setup instructions generated for that project instead.

## 🔐 Trust and Safety

CitySense AI aims to present information responsibly:

* Unverified citizen submissions are not treated as confirmed incidents.
* Missing incident data is not interpreted as proof of safety.
* Safety information should identify its source and date where available.
* The platform does not replace official emergency services or local authorities.
